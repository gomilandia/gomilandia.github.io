# Frontend de Gomiland

Consulta el README de la raíz para ejecutar, probar y publicar el sitio.

El juego vive en `src/GummyRain.jsx`; `src/gummyScene.js` carga el modelo y renderiza los ositos. `src/gummyPhysics.js` controla la caída, los rebotes y la puntuación. El archivo `public/models/gummy.glb` es el modelo original facilitado para el proyecto. Se reutiliza una sola geometría y cinco materiales translúcidos con los colores rojo, verde, naranja, amarillo y rosa.
